# ติดตั้งระบบทะเบียนสินทรัพย์บน Google Sheet

ข้อมูลเก็บใน Google Sheet รูปเก็บใน Google Drive หน้าเว็บทำด้วย Apps Script
ปุ่มพิมพ์ป้ายจะเปิด `print.html` บน GitHub Pages (Apps Script ใช้ Bluetooth ไม่ได้) ข้อมูลป้ายส่งไปในส่วนหลัง `#` ของลิงก์ ซึ่งไม่ถูกส่งไปที่เซิร์ฟเวอร์ GitHub

## 1. สร้างโฟลเดอร์และชีต
1. Google Drive → **ใหม่ → โฟลเดอร์** ตั้งชื่อ `ทะเบียนสินทรัพย์`
2. เข้าโฟลเดอร์ → **ใหม่ → Google ชีต** ตั้งชื่อ `ทะเบียนสินทรัพย์`

## 2. ใส่โค้ด
1. ในชีต เมนู **ส่วนขยาย → Apps Script**
2. ไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจาก [Code.gs](https://raw.githubusercontent.com/karnchaP-sudo/asset-register/main/apps-script/Code.gs)
3. กด **+** ข้างคำว่า ไฟล์ → **HTML** ตั้งชื่อ `Index` (ไม่ต้องพิมพ์ .html) ลบโค้ดเดิม แล้ววางโค้ดจาก [Index.html](https://raw.githubusercontent.com/karnchaP-sudo/asset-register/main/apps-script/Index.html)
4. กด **บันทึก** (ไอคอนแผ่นดิสก์)

## 3. ตั้งค่าชีตครั้งแรก
1. แถบด้านบน เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้**
2. Google จะขอสิทธิ์ → **ตรวจสอบสิทธิ์** → เลือกบัญชี → **ขั้นสูง** → **ไปที่ ... (ไม่ปลอดภัย)** → **อนุญาต**
   (ขึ้นคำว่าไม่ปลอดภัยเพราะเป็นสคริปต์ที่เราเขียนเอง ยังไม่ได้ส่ง Google ตรวจ)
3. กลับไปที่ชีต จะเห็นแท็บ Assets, Queue, Categories, Settings, Log และในโฟลเดอร์มีโฟลเดอร์ `รูปทรัพย์สิน`

## 4. เปิดเป็นเว็บ
1. Apps Script → **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
2. ไอคอนเฟือง → **เว็บแอป**
3. **ดำเนินการในฐานะ:** ผู้ใช้ที่เข้าถึงเว็บแอป
4. **ผู้ที่มีสิทธิ์เข้าถึง:** ทุกคนที่มีบัญชี Google
5. กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** เก็บไว้ (ลงท้ายด้วย `/exec`)

คนที่เปิดเว็บได้ต้องมีสิทธิ์ **แก้ไข** ชีตด้วย คนที่ไม่มีสิทธิ์จะเปิดแล้วขึ้นว่าโหลดข้อมูลไม่สำเร็จ

## 5. นำเข้าข้อมูลครั้งแรก
เปิด URL เว็บแอป → กด **นำเข้าไฟล์ข้อมูล** → เลือกไฟล์ `fa-data-import.json` ระบบจะบันทึกสินทรัพย์และรายการรอขึ้นทะเบียนลงชีตให้

## 6. ให้ทีมใช้งาน
แชร์ **โฟลเดอร์** `ทะเบียนสินทรัพย์` ให้ทีมเป็น **ผู้แก้ไข** (ทั้งชีตและรูปอยู่ในโฟลเดอร์นี้) แล้วส่ง URL เว็บแอปให้ ครั้งแรกแต่ละคนต้องกดอนุญาตสิทธิ์แบบขั้นที่ 3

## อัปเดตโค้ดภายหลัง
วางโค้ดใหม่ → บันทึก → **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้** → ดินสอ → เวอร์ชัน **ใหม่** → ทำให้ใช้งานได้ (URL เดิมใช้ต่อได้)

## พิมพ์ป้าย
กด **พิมพ์ป้าย** ในเว็บ → แท็บใหม่เปิดหน้าพิมพ์ → **เชื่อมต่อเครื่องพิมพ์** → เลือก NIIMBOT → **พิมพ์ทั้งหมด**
ใช้ Chrome หรือ Edge บนคอมพิวเตอร์หรือ Android (iPhone ใช้ไม่ได้) และต้องเปิด GitHub Pages ของ repo นี้ไว้
